# App-shot image bank (20 photos)

Phone / market-chart photos used by the `appshot` section and copied to `sites/<domain>/img/appshot.jpg`.

- Source: Pexels — https://www.pexels.com/
- License: Pexels License — free for commercial use, attribution not required
  (https://www.pexels.com/license/)
- Every file and its source page are listed in `manifest.json`.

The bank is rotated per plan (`plan.appshot`) so sibling offers do not reuse the same photo.
If you replace a file, keep the `manifest.json` `file` key in sync.
