# Trust badge bank

Brand/payment marks rendered under every lead form (`.form-trust`).

- Source: Simple Icons — https://simpleicons.org/
- License of the icon set: CC0 1.0 (public domain dedication)
- Each brand name and file is listed in `manifest.json`.

Trademarks remain the property of their owners. These marks are illustrative trust
signals for demo offers; do not present them as a partnership or endorsement.
The plan stores six badge keys in `plan.trust_badges`, and `assemble.py` copies only
those files to `sites/<domain>/img/trust/`.
